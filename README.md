# Task Manager
## Simple Django example

**How to run**
1. Clone the current project: ```git clone https://github.com/gprok/taskmanager.git```
1. cd into taskmanager
1. Create venv: ```python -m venv venv```
1. Activate venv: ```venv\Scripts\Activate```
1. Install dependencties: ```pip install -r requirements.txt``` 
1. Run: ```python manage.py runserver```
